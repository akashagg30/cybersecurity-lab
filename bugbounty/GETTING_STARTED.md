# 🚀 Getting Started with Bug Bounty

## Step 1: Create Accounts

### HackerOne (Recommended for Startups)
1. Go to https://hackerone.com
2. Sign up as a researcher
3. Complete your profile
4. Enable 2FA
5. Add your payment method

### Bugcrowd
1. Go to https://bugcrowd.com
2. Sign up as a researcher
3. Complete verification
4. Set up payment

## Step 2: Complete Your Profile

**Why?** Companies trust researchers with complete profiles.

**What to add:**
- Real name (or consistent alias)
- Skills and certifications
- Previous work (if any)
- Payment details
- Communication preferences

## Step 3: Start with Public Programs

**Public programs** = Anyone can test, no invite needed.

**Recommended first targets:**

| Program | Why | Bounty Range |
|---------|-----|--------------|
| Notion | Good documentation | $100-$10,000 |
| Linear | Modern tech stack | $100-$5,000 |
| Cal.com | Open source | $50-$2,000 |
| PostHog | Startup-friendly | $100-$5,000 |
| Railway | Cloud platform | $100-$5,000 |

## Step 4: Learn the Workflow

```
1. Read scope and rules
2. Enumerate attack surface
3. Test for vulnerabilities
4. Validate findings
5. Write clear report
6. Submit and wait
7. Respond to triage
8. Get paid!
```

## Step 5: Focus on Quality

**One great report > Ten poor reports**

**What makes a great report:**
- Clear, descriptive title
- Step-by-step reproduction
- Impact explanation
- Remediation suggestion
- Screenshots/evidence

## Step 6: Build Reputation

**How to build trust:**
- Submit quality reports
- Respond promptly to triage
- Help fix issues
- Be professional
- Avoid duplicates

## Step 7: Scale Up

**Progression path:**
1. Start with public programs
2. Get invited to private programs
3. Focus on higher bounties
4. Specialize in a niche
5. Build a team (optional)

---

## Common Mistakes to Avoid

❌ **Don't:**
- Test without authorization
- Submit duplicate reports
- Be rude to triage
- Rush to submit
- Ignore scope

✅ **Do:**
- Read rules carefully
- Take your time
- Be professional
- Learn from rejections
- Help improve security
