## Remediation

### Quick Fix
Implement Content Security Policy (CSP) header to mitigate XSS:

```
Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline'
```

### Proper Fix
1. Sanitize all user input before DOM manipulation
2. Use `textContent` instead of `innerHTML`
3. Avoid `eval()` and `document.write()`
4. Implement CSP headers

### Code Example
```javascript
// Vulnerable
element.innerHTML = userInput;

// Fixed
element.textContent = userInput;  // Safe - no HTML parsing
```
